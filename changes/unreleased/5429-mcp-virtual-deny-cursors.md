---
section: Security
issues: [#5429, #5253]
---
- **MCP registry listings no longer reveal held server versions through cursors, nested Virtual deny lists apply, and a gate outage or a long run of held versions no longer changes which version is served** (#5429, #5253). A held version (quarantined, refused, unresolvable, resolving, denied, deleted or awaiting Remote approval) is meant to be indistinguishable from a missing one for a reader, but several paths let it show through or let a lower-priority answer take its place.

  `nextCursor` on `/servers` (hosted, Remote and Virtual) and on the holds listing used to be base64 of `name:version` (or `m:<member>:<cursor>` on a Virtual) of the last row read, which could be a held row, and any hand-made cursor was accepted. Cursors are now opaque: sealed with AES-256-GCM under a key derived from `jwt_secret` and bound to the issuing repository and listing. A cursor this instance did not issue, including one from before the upgrade, is `400 mcp_invalid_query` ("invalid cursor"); start the listing again without it.

  A nested Virtual's `mcp_server_deny` was ignored when its parent Virtual was read; it now hides the name from every member reached through it (the union of the deny lists along the member's path). When a member's gate cannot be evaluated, Virtual listings used to list the same version from a lower-priority member and take `latest` from the next member; that version is now left out (a detail read still answers `503`). Hosted `version=latest` likewise no longer falls back to an older version when a newer one cannot be decided. `latest` now reads the newest 100 non-deleted versions on every surface, so `/versions/latest`, `isLatest` and `version=latest` agree for a server whose newest 100 versions are all held. The asynchronous package fill now recomputes its fill repository from the current mapping and fails the version (`mcp_package_not_found`, publish again) unless it is the Remote recorded at publish, instead of pinning the package under a mapping and a Remote from different moments.
