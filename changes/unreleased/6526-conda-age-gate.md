- **The Package Age Policy (age gate) now covers conda Remote channels and the Virtual channels over them** (#6526). Enabling it with `PUT /api/v1/repositories/{key}/age-gate` was refused for conda, and nothing enforced it. A gated Remote now leaves every held record out of its `repodata.json` (all encodings), `current_repodata.json` and CEP-16 shards, and a Virtual applies each gated member's gate, with shards derived from its filtered `repodata.json`. A held package file answers `451 age_gate_blocked` naming the reason, the age basis and the date it becomes available, and records a pending review. A file the upstream index does not list answers `404 age_gate_unlisted`. Gated documents carry `x-ak-age-gate-withheld: <count>`.

  On first enable the gate records one complete snapshot of each subdir as its baseline. Baseline files count as old unless a builder or index timestamp is recent, so the channel is not emptied, and the gate fails closed (503) until the baseline exists. Later files are recorded by filename and sha256 at the database clock and aged from their first sighting. An upstream `indexed_timestamp` earns credit only back to the previous read of the subdir, capped by `CONDA_AGE_GATE_REFRESH_CAP_SECS`; an older one is flagged as backdating. A record with a future builder `timestamp`, or one indexed before it was built, is held. A repoint or a gate toggle never re-baselines: `POST /api/v1/repositories/{key}/age-gate/conda/rebaseline` does, and is audited as `AGE_GATE_REBASELINED`. `GET .../age-gate/conda/withheld?subdir=` says why each file is withheld. The gate is not retroactive: it cannot help if the upstream was compromised before the baseline.

  Migration 427 adds the sighting ledger (two new tables). The gated document is built once per cached upstream document and kept by the conda merge cache. A rebuild writes only files it has not recorded and reads back only the post-baseline sightings inside the gate window, so there is no per-record query on the request path. A gated Remote's `repodata.json.sig` answers 404, since the upstream signature no longer covers the filtered document. See `docs/conda-cooldowns.md`.
