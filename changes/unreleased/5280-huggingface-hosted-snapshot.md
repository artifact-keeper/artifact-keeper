- **`snapshot_download` works against a hosted Hugging Face repository** (#5280). With `HF_ENDPOINT` pointed at a Local `huggingface` repository, `HfApi().model_info` and `snapshot_download` failed: the model-info document had no `id` key (which `huggingface_hub`'s `ModelInfo` requires) and a revision name where a timestamp belonged, its `siblings[].rfilename` were the stored `{model}/{revision}/{file}` paths of every revision instead of the requested revision's paths inside the repository, and the synthetic commit it reported as `sha` was not understood by the tree and resolve routes, so every file `snapshot_download` requested at `/resolve/<sha>/<file>` answered 404. Model info now has the Hub's shape (`id`, `modelId`, Hub timestamps, relative `rfilename`s of the requested revision only), the model-info, tree and resolve routes accept the synthetic commit in place of the revision it stands for, model info without a revision describes `main`, and an unknown revision answers 404 with `X-Error-Code: RevisionNotFound`. `list_models` entries also gained `id` and a real `lastModified`. Remote (proxy) repositories are unchanged. README and the format registry no longer claim dataset support, which the format never had.
