- **The event stream, peer and transfer reads, and OCI replication writes are scoped to the caller** (#5393). `GET /api/v1/events/stream` forwarded every domain event to any signed-in user. An administrator still receives every event. Anyone else now receives only the events of repositories it may read, without the actor, and only for MCP server versions it is served. Events about users, groups, permissions, service accounts and quality gates are for administrators, except a `user.*` event about the caller itself. The `GET` routes under `/api/v1/peers` (a peer, its sync tasks, subscriptions, labels, connections, chunk availability and transfer sessions) now require an administrator, like their mutations. `GET /api/v1/peers` still answers a non-admin `200`, so a peer's heartbeat keeps working, but lists no peer. The OCI replication receive routes (`PUT /api/v1/repositories/{key}/oci/blobs/{digest}` and `/oci/manifests/{digest}`) now refuse a repository that is not an OCI repository, so a writer can no longer create OCI rows in an npm, Maven or MCP repository.
