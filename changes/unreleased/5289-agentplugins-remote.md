- **Agent Plugins Remote repositories proxy another Artifact Keeper's hosted Agent Plugins repository** (#5289). Creating an `agentplugins` repository with `repo_type: "remote"` and `upstream_url` set to the central repository (`https://central.example.com/agentplugins/<key>`, or the `/agentplugins/t/<token>/<key>` form) is now accepted. The Remote serves `marketplace.json`, the per-harness marketplaces and `{name}/index.json` fetched through the proxy cache, with every archive URL rewritten to point at the Remote and every `sha256` kept exactly as the upstream lists it, so `claude plugin install` and `ak agent plugins install` verify the same bytes on every instance. Archive downloads are checked against the `sha256` in the upstream index before they are cached or served: a mismatch is answered with `502` and never cached, and a matching archive is cached as immutable and served without contacting the upstream again. Upstream credentials, the upstream filter, the origin policy and the proxy cache settings apply as for every other Remote. Virtual Agent Plugins repositories are still refused, now with a message naming the follow-up; hosted repositories are unchanged.
