- **Code coverage becomes a merge gate: it measures production code only, diffs against the true merge base, and is rolled out shadow-first with a grace date and an audited maintainer override** (#4220). The coverage floor and the new-code gate counted inline `#[cfg(test)]` modules as covered code; they are 65% of the instrumented lines at ~98% hit, so the old 50% floor read 90.4% while production code sat at 76.6%, and a pull request that added well-tested test code and untested production code could pass the 70% new-code gate. `scripts/ci/coverage-gate.py` now excludes those modules (the rule `jscpd-prepare-sources.py` already applies, plus files declared by a `#[cfg(test)] mod x;`) from both gates, lists every uncovered new line in the job summary, and the floor is recalibrated to 76% of production lines. The new-code diff is taken from the merge base the compare API reports for the measured merge commit (`scripts/ci/coverage-merge-base.sh`) instead of a 200-commit shallow walk that fell back to the base tip, so branches far behind `main` no longer count other PRs' lines as their own (#1646). The duplication gate stays advisory.

  `✅ CI Complete` now decides whether a coverage failure blocks, from `.github/coverage-gate.json`: in `shadow` mode (this change) it only reports what it would do. With `"mode": "enforce"`, a floor or new-code failure, or a run that measured nothing, fails CI Complete unless the pull request was created before `enforce_after` (2026-10-08), is a draft, carries the `coverage-grace` label, or has a maintainer override: the `coverage-override` label applied by a user with admin or maintain permission plus a `/coverage-override <reason>` comment by such a user, with both names and the reason written to the job summary. A Backend Unit Tests job skipped by the existing skip rules needs no coverage; a failed one fails the gate with that reason. The workflow now also runs when a draft is marked ready for review, so the draft exemption cannot outlive the draft. CI-only; nothing shipped changes.
