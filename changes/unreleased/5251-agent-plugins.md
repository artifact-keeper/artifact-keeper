- **Agent Plugins repositories host AI coding-agent plugin bundles for Claude Code, Cursor, Codex, Copilot / VS Code and the Agent Plugins Standard** (#5251). A new hosted-only `agentplugins` format stores one zip per plugin version at `/agentplugins/{repo}/{name}/{version}/{name}-{version}.zip` (streamed `PUT`, optional `X-Checksum-Sha256`, `409` on an existing version) and generates `marketplace.json`, `claude-marketplace.json`, `cursor-`/`codex-`/`vscode-marketplace.json` and `{name}/index.json` from the database on every request, with `ETag`/`304`, the latest SemVer version per plugin, and quarantined or held versions left out. Claude Code adds a repository directly with `claude plugin marketplace add <url>/claude-marketplace.json`; a private repository is read either through `extraKnownMarketplaces` with an `Authorization` header, or with a read token in the path (`/agentplugins/t/{token}/{repo}/...`, `Cache-Control: private, no-store`), and archives are always streamed from the server's own origin so the configured headers reach them.

  Publishing refuses a zip with no harness manifest, an unsafe or symlinked entry, an ambiguous plugin root, a non-SemVer version, or a manifest whose `name` or `version` differs from the path: Claude Code resolves a plugin's version from `plugin.json` first, so a stale manifest version would freeze every install. Remote and virtual repository creation is refused with `400`. See `docs/agent-plugins.md`.
