- **The WASM plugin runtime moves to wasmtime 36.0.21** (#6273). It fixes RUSTSEC-2026-0566 (wasmtime-wasi: host memory grows without bound on empty writes to `AsyncWriteStream`), RUSTSEC-2026-0569 (panic in `Caller::get_module_export`) and RUSTSEC-2026-0571 (wasmtime-wasi-http: heap use grows without bound on empty HTTP/2 body writes). The same batch also lists RUSTSEC-2026-0573 and RUSTSEC-2026-0567, which are fixed only in wasmtime 48 and later. Neither can be reached here: upstream scopes them to wasmtime 47+ and 39+, and they need the Wasm GC proposal with a fixed GC heap or memory reservation, or a build without the `threads` feature, and the plugin engine uses none of these. Both are ignored in `.cargo/audit.toml`, with that reasoning written next to each ignore.
