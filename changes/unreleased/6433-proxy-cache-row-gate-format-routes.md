- **Format routes serve a Remote's cached file from its `artifacts` row only after checking the cache sidecar** (#6433). #6416 put a Remote's cached file recorded as an `artifacts` row (rows written before 1.2.0) behind the cache sidecar on the PyPI virtual walk. Every other route that serves such a row read it with row-level checks only, so an entry inside its Package Age Policy hold, one past its TTL and one whose stored scan verdict refuses it were served. That covered PyPI PEP 658 metadata, conda, Alpine, RPM, Debian, Go modules, the generic download route (`/api/v1/repositories/{key}/download/...` and `/general/...`, presigned redirect, range and `HEAD` included), the tree content view, and the package routes of Cargo, Chef, JetBrains, VS Code, Git LFS, sbt, Hugging Face, Buf/protobuf, NuGet, Conan, Composer, CocoaPods (packages and podspecs), Pub, Swift (archives and manifests), Terraform, Hex, Ansible, CRAN, Helm, Puppet and RubyGems, plus the shared local fetches. Each now passes the #6416 single-read gate first. A held entry answers the hold's `409` and a refusing origin policy or verdict `403`. An entry that is stale, has no readable sidecar, is another Remote's entry, or was refilled at another size is treated as no row: the Remote resolves the file through its proxy path, which revalidates or refetches it under every gate. A PEP 658 metadata request answers the `507` the PyPI virtual walk recovers from that member's own upstream. Rows of hosted repositories are unaffected and cost no extra read.
