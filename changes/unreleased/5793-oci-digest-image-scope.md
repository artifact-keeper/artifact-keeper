- **Hosted OCI repositories resolve manifest and blob digests only under the image name that holds them** (#5793). `GET`/`HEAD /v2/<repo>/<image>/manifests/<digest>` and `/blobs/<digest>` answered `200` under any image name in the repository, including one that was never pushed. A manifest digest now resolves under `<image>` only when that image holds it: a tag or by-digest push under it, an index live under it that references it, or a push, promotion, replication or import under it. That last case keeps the old digest of an overwritten tag pullable under its own image (#1681). A blob resolves when it was uploaded or mounted under the image, or a manifest that resolves under the image references it. Anything else answers `404 MANIFEST_UNKNOWN` / `404 BLOB_UNKNOWN`, the blob check before the scan re-block (so `404`, not `403`). The #4525 rule for a digest deleted under one image is unchanged. Virtual repositories resolve a hosted member's digests the same way, and the referrers API lists only referrers that resolve under `<name>`. Remote repositories are unchanged. A mount from another image of the same repository (`mount=<digest>&from=<repo>/<image>`) is now honoured (`201`, `202` when that image does not hold the blob).

  Upgrade: migration 363 adds three tables (`oci_image_manifests`, `oci_image_blobs`, `oci_image_scope_backfill`) and no data. The `oci_manifests` reconcile, at startup and every `OCI_MANIFESTS_RECONCILE_INTERVAL_SECS`, links existing manifests to their images; each repository keeps the old repository-wide rule until its first pass completes. Digests of tags overwritten before the upgrade get a legacy marker and stay pullable under image names that already hold content in the repository. Pushes served by 1.11 replicas during a rolling upgrade are linked on the next pass. Pushing an existing layer under a new image name uploads it again unless the client mounts it; no extra storage is used. `AK_OCI_BLOB_SCOPE=report` temporarily restores repository-wide blob reads (it serves the read and counts `ak_oci_blob_scope_misses_total`) and will be removed in 1.13. A restore from a pre-1.12 archive resets the restored repositories to the old rule until the next pass. See `docs/operations/oci-image-scope.md`.
