- **wasmtime moved to 36.0.20 for RUSTSEC-2026-0424, pulldown-cmark to 0.13.6 for RUSTSEC-2026-0433, and RUSTSEC-2026-0429 ignored on utoipa-swagger-ui's build-time zip** (#5162). The wasmtime advisory lets a component that receives a borrow of a resource it defines itself grow host memory that is never charged to the store, so it bypasses the plugin host's store limits; AK's plugin host runs component-model plugins with WASI, so an installed plugin could have exhausted backend memory. Installing a plugin requires an administrator. All `wasmtime-*`, `cranelift-*`, `pulley-*`, `wiggle-*` and `winch-codegen` crates move together. pulldown-cmark is a build-time dependency (via `prost-build`) and is not linked into the backend. zip 2.4.2 is only a build dependency of utoipa-swagger-ui 8.1.0, whose build script unpacks the bundled Swagger UI with its own `by_index` loop and never calls `ZipArchive::extract`; the backend's own zip is 9.x.
