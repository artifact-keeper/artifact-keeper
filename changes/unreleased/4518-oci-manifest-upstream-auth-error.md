- **An OCI Remote whose upstream registry refuses its credentials on the manifest request itself now reports an upstream authentication failure instead of "manifest unknown"** (#4518). #4453 covered a 401/403 from the upstream's token service. A 401/403 from the registry on the manifest request itself was still reported as `404 MANIFEST_UNKNOWN`. That happened after a successful token exchange whose token the registry then refused, and for an upstream that uses plain Basic auth and rejects the credentials. When the Remote's upstream credentials were actually sent, a direct Remote manifest GET or HEAD now fails with `502` and the OCI error code `DENIED`. The backend also logs a warning on the `security` target naming the upstream URL (redacted, no credentials), at most once a minute per Remote, with a count of the warnings suppressed in between. When no credentials were sent, the refusal keeps `404 MANIFEST_UNKNOWN` and is logged at INFO. That covers a Remote without credentials, and a token obtained anonymously because the realm is not trusted (#4527). The reason: an anonymous refusal usually means the image does not exist or is private (Docker Hub answers 401 for a repository that does not exist). Generic proxy formats are unchanged.
