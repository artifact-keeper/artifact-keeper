- **Lifecycle policies now reclaim the proxy cache of Remote repositories** (#3734). Until now the lifecycle executors only looked at `artifacts`, while a Remote repository records what it proxies in `proxy_cache_artifacts`. Storage GC leaves `proxy-cache/*` objects alone, so a long-lived Remote repository's cache grew without bound. In a Remote repository, `max_age_days` now evicts cache entries whose `cached_at` is older than the window, and `no_downloads_days` evicts entries that were cached before the window and have not been served or downloaded inside it. Each eviction deletes the `__content__` body and the `__cache_meta__.json` sidecar, then removes the catalogue row. If a storage delete fails, the row stays and the entry is retried on the next run. `match.path_prefix` applies to the cached path. Preview and execute report cache entries in a new `proxy_cache` object on the result (`entries_matched`, `entries_removed`, `bytes_matched`, `bytes_freed`, `skipped_reason`), separate from the artifact counters. `last_run_items_removed` counts both.

  **A policy that cannot reclaim anything in a Remote repository is now refused with 422** when you create it, attach it, or change its config, instead of being accepted and matching nothing. This covers `max_versions`, `tag_pattern_*` and `size_quota_bytes`, and also `exclude` lists and `min_keep`, which match artifact versions that cache entries do not have. OCI Remote repositories (Docker, Podman, Helm OCI and the like) are exempt because pulled manifests have `artifacts` rows. Policies that were already assigned keep running, and they can still be renamed or disabled. A global policy that has no proxy-cache meaning names the reason in `proxy_cache.skipped_reason`.
