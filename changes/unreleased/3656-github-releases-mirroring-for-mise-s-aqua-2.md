- **GitHub-Releases mirroring for mise's aqua backend, documented and cached properly** (#3656) (docs/mise-aqua.md). aqua packages are plain downloads from `github.com/<owner>/<repo>/releases/download/<tag>/<asset>`, and mise ≥ v2025.9.3 can rewrite those URLs to a mirror via `settings.url_replacements` — so a `generic` remote repository with `upstream_url: https://github.com` already serves as the mirror; no new format was needed. What was missing: the cache classifier had no rule for the shape, so every release asset was cached under the conservative 5-minute mutable TTL and revalidated against GitHub on a schedule, which is exactly the traffic a mirror exists to absorb. `classify()` now recognises the tag-pinned `{owner}/{repo}/releases/download/{tag}/{asset}` shape on `generic` repositories as immutable (cache forever, never revalidate); everything else generic keeps the mutable default, and generic coordinates remain swap-protected (`is_explicitly_mutable_index` is unchanged). The github.com → `objects.githubusercontent.com` redirect hop this flow depends on is now pinned by a regression test: reqwest must keep stripping `Authorization` on the cross-origin hop, so a repository-configured GitHub PAT reaches github.com but never the S3 host (which would reject the request — and must not see the token). Ships with `scripts/native-tests/test-mise.sh`, an end-to-end check that creates the repository, verifies a checksummed asset download through the proxy, and runs a real pinned `mise install aqua:jqlang/jq@1.7.1` through `url_replacements`.
