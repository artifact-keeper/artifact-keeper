- **Traces now cover the remaining upstream calls, carry the route, status, repository and cache outcome on the request span, show the authentication, virtual-resolution and proxy-fetch phases, and can include one span per database query** (#4455, #3954). The upstream requests made outside the proxy service now run in the same `otel.kind = client` span with `traceparent` injection as the proxy service's own: the PyPI JSON publish-time lookup, the npm change-feed consumer, the npm audit and `/-/` passthroughs, the Go checksum-database proxy, and the AWS ECR/CodeArtifact token exchange.

  The `http_request` server span now records `http.route` (the matched route pattern), `http.response.status_code`, `http.response.body.size` (when the length is known up front), `artifact_keeper.repository.key` (once the key names an existing repository) and `artifact_keeper.cache.outcome` (`hit`, `miss_expired`, `miss_no_metadata`, `negative_hit`, ...). A 5xx response sets `error.type` and the span's error status; a 4xx does not, per the HTTP server semantic conventions. The repository key and cache outcome are span attributes only, not metric labels. Three `INTERNAL` phase spans appear under it: `authenticate` (credential validation for the format and optional-auth routes), `resolve_virtual_members` (a virtual repository's member resolution) and `proxy_fetch` (a proxy fetch: cache lookup, the upstream `CLIENT` span, cache write).

  With OpenTelemetry export configured, each SQL statement sqlx reports becomes a `CLIENT` span named after its operation and table (for example `SELECT repositories`) with `db.system.name`, `db.operation.name`, `db.collection.name` and `db.response.returned_rows`, parented to the span the query ran under. The statement text is not copied onto the span. These spans follow the `sqlx::query` log filter: with the default `RUST_LOG` only statements sqlx reports as slow (over 1 s) produce one, and `sqlx::query=debug` in `RUST_LOG` produces one per statement, which also logs every statement to stdout. A query outside any request or job span produces none.
