---
section: Security
issues: [#5459, #5109]
---
- **A destination sent through an environment proxy is now checked against the outbound address policy, whatever the case of the proxy variable** (#5459, #5109). Under `HTTP_PROXY`, `HTTPS_PROXY` or `ALL_PROXY` (upper or lower case) the backend handed a Remote's host name to the proxy without checking where it resolved, because a proxied request never reaches the connect-time resolver guard; with private upstreams disabled, a repository administrator could have a sync accept loopback content fetched through the proxy. The SSRF-guarded clients (Remote fetches, webhooks, SSO discovery, internal services) now read the proxy variables with the same rules `reqwest` uses, and before a destination goes to the proxy they resolve it (with a 5-second limit) and refuse it when it does not resolve or when the direct path would refuse any of its addresses. The check runs on every new connection, every redirect hop and every plain-HTTP Remote request (a forward-proxied `http://` connection is reused per host); webhook and SSO clients keep no idle plain-HTTP proxy connection. `NO_PROXY` destinations connect directly and stay checked at connect time. `AK_UPSTREAM_ENV_PROXY=ignore` keeps Remote and other upstream fetches off the environment proxy altogether, and the backend warns at startup when it inherits a proxy with `UPSTREAM_ALLOW_PRIVATE_IPS=false`.

  The proxy still resolves the name itself: an answer that changes between the backend's lookup and the proxy's (active DNS rebinding) is for the proxy's own destination policy to refuse, so give the proxy one that refuses loopback, link-local, metadata and internal ranges.

  **Upgrade note.** Proxied destinations that the backend resolves to private addresses are now refused unless `UPSTREAM_ALLOW_PRIVATE_IPS` or `AK_SSRF_ALLOW_PRIVATE_CIDRS` admits them, as they already were on the direct path. This affects internal mirrors reached through a corporate proxy, and storage on private endpoints (for example Azure Private Link) reached through the proxy. The backend now also sends its own DNS queries for proxied host names, and refuses a host it cannot resolve: where it can reach DNS only through the proxy, give it a resolver or set `AK_UPSTREAM_ENV_PROXY=ignore`.
