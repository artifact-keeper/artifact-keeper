- **Packages and package versions report their real download counts** (#5346, #5260). `download_count` on `GET /api/v1/packages`, `GET /api/v1/packages/{id}` and `GET /api/v1/packages/{id}/versions` read the `packages` / `package_versions` columns, which nothing ever incremented, so every package in every format showed 0. The counts are now computed when the catalog is read, from the same download history the artifact download stats use: a version counts the downloads of its files in `download_statistics` (the artifact with the version's checksum and the files recorded under the package's name and version, such as every file of a Hugging Face model revision), plus, on a Remote repository, the pull-through serves in `proxy_download_statistics` that carry the version's digest. A package reports the sum of its versions. Nothing is added to the download path, and a listing page costs one extra query. A Remote version cataloged without a digest (a streamed Maven pull-through) cannot be tied to its serves and reports `null` instead of a misleading 0; `download_count` is therefore nullable in the OpenAPI schema. The stored columns are left in place, unused.
