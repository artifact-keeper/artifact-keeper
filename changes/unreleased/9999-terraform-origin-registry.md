- **Hosted Terraform repositories now work as an OpenTofu/Terraform origin provider registry** (#9999). The package document had no `shasums_url`, `shasums_signature_url` or signing keys, so `tofu init` / `tofu providers lock` failed with `checksum list has no SHA-256 hash`, and `/.well-known/terraform.json` was only served per repository. Hosted repos now serve a deterministic `SHA256SUMS` document and a binary detached OpenPGP signature (`SHA256SUMS.sig`) made with the repository's existing signing key, and advertise both plus the public key in the package document. Without a configured signing key the new routes return 404 and the package document is unchanged. Protocols come from the `X-Terraform-Protocols` upload header or the ZIP's `terraform-registry-manifest.json` (default `5.0`). Setting `TERRAFORM_DEFAULT_REPO` makes `GET /.well-known/terraform.json` resolve host-level source addresses to that repository; see `docs/terraform-registry.md`.
