- **An OCI Remote whose upstream token service rejects its credentials now reports an upstream authentication failure instead of "manifest unknown"** (#4453). A 401 or 403 from the upstream's bearer token endpoint was logged as `Storage error` and the client got `404 MANIFEST_UNKNOWN`, so wrong upstream credentials looked like a missing image. When the Remote's credentials were actually sent to the token service, the pull now fails with `502` and the OCI error code `DENIED` ("upstream registry authentication failed"). The backend also logs a warning on the `security` target naming the token service (redacted, no credentials), at most once a minute per Remote, with a count of the warnings suppressed in between. A refusal of an anonymous token request still reports `404 MANIFEST_UNKNOWN` and is logged at INFO. That covers a Remote without credentials, and one whose credentials were withheld from an untrusted cross-origin realm (#4527). Other token-endpoint failures are unchanged.
