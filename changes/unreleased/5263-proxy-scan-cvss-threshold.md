- **The proxy scan gate can block by CVSS score** (#5263). The gate compared scanner severity categories, so "block CVSS 8.0 and above" could not be expressed: two `high` findings scored 7.5 and 8.1 got the same decision, and raising the threshold to `critical` is a different policy. A repository's scan configuration gains `cvss_threshold` (`0.0` to `10.0`, `null` by default), live under the same `block_on_policy_violation` opt-in as `severity_threshold`. When set, a finding that carries a CVSS base score blocks at or above the number whatever its severity label, and a finding with no score is still graded by `severity_threshold`. Nothing changes for a repository that does not set it.
  Grype's CVSS data is now kept: each proxy finding carries the score, CVSS version, vector and source it was graded by (`cvss` on the finding), chosen by a documented precedence (the matched advisory record before its related records; primary before secondary; newest CVSS version; highest score). The verdict row stores the highest score and the highest unscored severity (migration 361), so a cached verdict is compared with each repository's own threshold by the same rule as a fresh scan, and the Virtual stricter-of-two rule, the OCI blob and referrer checks, the proxy-cache fast paths and the blocked-proxy dashboards all grade through that one decision.
  A verdict recorded before the upgrade has no CVSS summary; a repository that sets `cvss_threshold` blocks it until the digest is scanned again. The instance lock treats raising or clearing the number, and trading a severity threshold for a numeric one in either direction, as weakening. `PUT /api/v1/repositories/{key}/security` takes the field three ways (omit to keep, `null` to clear, a number to set); scan-config change audit entries carry it. See `docs/security/scan-on-proxy.md`, "Blocking by CVSS score".
  Numeric gates also evaluate scored `info` findings; categorical policies retain the `info` exemption. Summaries are computed before deduplication so a scored copy cannot erase an unscored severity fallback. Malformed descriptive CVSS metadata does not discard a valid score, and enforcement reads require both summary columns. An unpinned rescan of a legacy request-pinned verdict retains its unknown summary until the coordinate can be graded again.
