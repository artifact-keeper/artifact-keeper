section: Changed
issues: [#4234, #4260, #4247, #4243, #4194, #4383, #1619, #1936, #1529]

- **CI runs the backend unit tests as five shards on GitHub-hosted runners, and gains scheduled whole-repo duplication, mesh and OCI-on-S3 runs** (#4234, #4260, #4247, #4243, #4194, #4383). The instrumented unit-test build peaked at 16.7 GiB in one rustc process and kept being killed on the self-hosted pool; inline test modules now carry an `ak_test_shard` gate and run as a five-leg matrix on `ubuntu-latest`, aggregated under the same required `🧪 Backend Unit Tests` check (#4234). A module without a gate now warns and runs in exactly one leg instead of failing Check Rust (#4260), and the one module that landed ungated was gated (#4247). The coverage gate warns when the report holds lines past the end of a file, the signature of stale coverage objects (#4243). Dependabot no longer proposes the hand-managed Rust toolchain pin or `x509-cert` majors that sigstore cannot build against (#4194). The scheduled workflow adds a weekly whole-repo duplication report (#1619), a nightly two-peer mesh end-to-end run that now actually syncs an artifact (#1936), and a nightly OCI push/pull against MinIO and the filesystem backend (#1529) (#4383). No shipped behaviour changes.
