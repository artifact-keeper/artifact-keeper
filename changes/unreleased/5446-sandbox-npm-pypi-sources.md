section: Security
issues: [#5446]
---
- **The MCP sandbox refuses an npm or PyPI job whose registry, package coordinates, arguments or environment could make `npx`/`uvx` install from anywhere but the Artifact Keeper repository it was served from** (#5446). The worker accepted any `registryBaseUrl` that started with the job's AK base URL as a string, so a host-prefix lookalike (`ak.example.test.evil`), userinfo, an encoded authority, another port, an encoded or dot-segment path, or a query or fragment still rendered into the guest's `npx --registry` / `uvx --default-index`, and a package name or version could itself be a URL, git or file spec. `render-sandbox` and the job loop now parse the registry as a URL and require exactly `<akBaseUrl>/npm/<repository>` or `<akBaseUrl>/pypi/<repository>` by scheme, IDNA-normalised host, effective port and path, and pass on its canonical form; userinfo, any percent-encoding, backslashes, dot segments, queries and fragments are refused. The package must be a plain name with one exact version (SemVer without build metadata for npm, PEP 440 for PyPI), so `name@url`, `git+`, `github:`, `file:`, `npm:` aliases, archive file names, direct references, ranges and tags are refused. Environment variables the job's package manager reads for its source or configuration (npm: `npm_config_*` in any case, `YARN_*`, `PNPM_*`, `COREPACK_*`, `NODE_OPTIONS`; PyPI: `UV_*`, `PIP_*`, `PIPX_*`) are refused instead of dropped, and so is a source option with a URL, `git+` or `file:` value in `packageArguments` or `runtimeArguments` (`--registry`, `--@scope:registry`, `--index-url`/`-i`, `--extra-index-url`, `--find-links`/`-f`, `--default-index`, `--index`, `--from`, `--with*`). Every refusal happens before a guest starts and is reported `unsupported`, naming the field and the rule but never the submitted name or value. For npm and PyPI guests, inputs whose name ends in a credential word (`*_TOKEN`, `--password`, `*_API_KEY`, ...) now get the `AK_PLACEHOLDER_<NAME>` placeholder even when they are not marked secret, and an `akBaseUrl` with userinfo, a query or a fragment is refused.

  Upgrade note: an npm package version must now be an exact SemVer version without build metadata and a PyPI version an exact PEP 440 version; a job whose version is a range or tag is refused rather than resolved in the guest.
